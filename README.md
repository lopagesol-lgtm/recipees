# Clover Table Kitchen

Single-page US-inspired food recipe website in the MapleRidge / Westhaven split-image style, with two bundled JPG photos and three complete recipes.

## Open directly
Extract the whole ZIP, then double-click public/index.html. Keep hero.jpg and about.jpg next to it. No build step or CDN is required.

## Run locally
Install Node.js 22. Run npm install, then npm start. Open http://localhost:3000.

## Heroku
Deploy the extracted project root, where package.json, server.js and Procfile are located. Heroku installs dependencies automatically and uses the assigned PORT. No build step required. A paid Heroku dyno may be needed.
